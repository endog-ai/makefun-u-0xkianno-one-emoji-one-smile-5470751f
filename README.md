# makefun-u-0xkianno-one-emoji-one-smile-5470751f

One emoji, and nothing else — two people in an embrace, the warmest single character for making a stranger smile. A hug shared between two people is warmth itself: not a face smiling alone, not a symbol of warmth, but warmth happening between people. It stands apart from the crowded field of single smiling faces, suns and flowers, and it answers the brief exactly as written: no words, no caption, no explanation.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), as UTF-8 with
no trailing newline. The entry is exactly one emoji: PEOPLE HUGGING (U+1FAC2).
